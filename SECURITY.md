# Security policy

## Supported versions

The `0.1.x` series is the current supported release line.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not publish credentials, private browsing data, or an exploit before maintainers have had a chance to respond.

The CLI sends the normalized requested domain to the configured public data sources. It does not accept API keys or cookies. It stops on access refusal and does not attempt to bypass challenges.
